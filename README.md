# Find All My Tags

**Alle deine Google-Find-Hub-Tags gleichzeitig auf einer Karte.**
*All your Google Find Hub tags on one map at the same time.*

**⬇ [APK herunterladen / Download APK](https://github.com/cpuhl51/find-all-my-tags/releases/latest/download/FindAllMyTags.apk)** · [Alle Versionen / All releases](../../releases)

Die Google-App „Find Hub“ zeigt immer nur einen Tag. Find All My Tags zeigt alle auf einmal, jeden mit eigenem Symbol, und merkt sich den Standortverlauf.

## Funktionen

- Alle Tags auf einer Karte, mit Farben und Formen oder schlichten Symbolen
- 📶 **In der Nähe:** erkennt per Bluetooth, welche Tags gerade bei dir sind
- ⚠ Warnung, wenn ein Tag lange nicht gesehen wurde (oft leere Batterie)
- Standortverlauf, Orten, Klingeln (einzeln oder alle), Teilen
- Hell/Dunkel, Deutsch/Englisch, Zönose- oder klassische Knöpfe
- Deine Daten bleiben auf deinem Handy (optional Sicherung in deinem Google Drive)

## Installieren

1. Die APK über den Link oben auf dem Android-Handy herunterladen und öffnen.
2. Android fragt beim ersten Mal, ob dein Browser Apps installieren darf: erlauben.
3. In der App mit dem Google-Konto anmelden, das du in Find Hub verwendest. Die Hilfe-Seite in der App führt dich durch.

Updates installierst du genauso: neue APK herunterladen und über die alte installieren. Deine Daten bleiben erhalten.

## Wichtig zu wissen

- Google bietet keine offizielle Schnittstelle für Find Hub. Die App nutzt das Open-Source-Projekt [GoogleFindMyTools](https://github.com/leonboe1/GoogleFindMyTools). Eine Änderung bei Google kann sie zeitweise stören.
- Die Nutzung erfolgt auf eigene Verantwortung, siehe [LEGAL.md](LEGAL.md).
- Nicht im Google Play Store, weil die App eine inoffizielle Google-Schnittstelle nutzt.

### English

Google's Find Hub app shows one tag at a time. Find All My Tags shows them all at once, each with its own symbol, keeps the location history, marks tags nearby via Bluetooth (📶) and warns when a tag hasn't been seen for a long time. Download the APK above, allow installing from your browser, sign in with the Google account you use in Find Hub. Your data stays on your phone. Uses the unofficial [GoogleFindMyTools](https://github.com/leonboe1/GoogleFindMyTools); use at your own risk. Based on [tag-tracker](https://github.com/BKrepublic/tag-tracker), GPL-3.0.
